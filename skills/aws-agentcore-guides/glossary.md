# Glossary — AWS AgentCore Guides

**A2A** — Agent-to-agent protocol (Google origin, Linux Foundation; v1.0 GA Mar 2026); horizontal agent↔agent, vs MCP vertical agent↔tools (ch02, ch07, ch15)
**ADOT** — AWS Distro for OpenTelemetry; `opentelemetry-instrument` auto-instruments agent code and emits spans (ch01, ch06)
**Agent Card** — JSON at `/.well-known/agent.json` describing an A2A agent's skills, endpoint, auth (ch07)
**Agents-as-Tools** — Strands pattern: specialist agent wrapped in `@tool`; docstring = routing rule (ch09)
**Agents Classic** — Bedrock Agents after the 2026-06-30 rename; closed to new customers 2026-07-30 (ch03, ch08)
**allowedTools** — Harness setting restricting what the model may pick; omitted ⇒ all tools allowed; does not restrict the API (ch08)
**Application Inference Profile** — Bedrock profile for cost tagging/attribution (ch03)
**ARD** — Agentic Resource Discovery spec v0.91 (Proposal): `/.well-known/ard.json`, `POST /search`, federation auto/referrals/none (ch12)
**BedrockAgentCoreApp** — SDK HTTP server (port 8080, `/ping`, NDJSON streaming) wrapped by `@app.entrypoint` (ch04, ch09)
**Cedar** — Policy language for AgentCore Policy; default deny, `forbid` beats `permit`, JWT claims as tags (ch05)
**Circuit breaker** — Per-dependency failure counter (e.g. 5 fails / 30 s) that fails fast (ch10)
**Code Interpreter** — Managed sandbox; state persists until `stop()`; default 15 min/3,600 s, max 8 h (ch01, ch04)
**CompactingSessionManager** — Sample session manager compressing context above a token threshold (ch04)
**Contextual Grounding Check** — Guardrail scoring grounding/relevance; defense against hallucination and indirect injection (ch03, ch11)
**Converse** — Model-agnostic Bedrock chat API; the default over InvokeModel (ch03)
**CRIS** — Cross-Region Inference (`us.`/`global.` prefixes); absorbs throttling, affects data residency (ch03, ch10)
**customJWTAuthorizer** — Runtime/Gateway inbound auth via `discoveryUrl` + `allowedClients` (ch05)
**Denial of Wallet (DoW)** — Bots burning inference budget; countered with WAF rate limits + Bot Control (ch11)
**Discovery plane** — Agent Registry data plane exposing only APPROVED records (`*Discoverable*` APIs) (ch12)
**Endpoint (Runtime)** — URL to a version; `DEFAULT` follows latest, named endpoints pinned (ch01, ch08, ch10)
**Events / Memories** — AgentCore Memory short-term synchronous history vs long-term async-extracted records (ch01, ch04)
**Export to code** — `agentcore export harness` → Strands Python + `EXPORT_NOTES.md`; loses harness input validation (ch08)
**Fail-closed trimming** — ACL failure returns error, never partial results (ch14)
**Gateway** — Managed MCP endpoint over Lambda/OpenAPI/Smithy targets; tools named `Target___Tool` (ch01, ch05)
**Governance plane** — Agent Registry control plane holding all record states, IAM only (ch12)
**Graph** — Strands `GraphBuilder`: deterministic nodes, conditional edges, bounded cycles (ch09)
**Guardrails Shadow Mode** — Log-only guardrail hook before ENFORCE (ch07, ch10)
**Harness** — AgentCore managed agent loop: config (CreateHarness, 18 fields) instead of loop code (ch08)
**InvokeAgentRuntimeCommand** — Runs shell commands in a session microVM, bypassing the model; restrict via IAM (ch08)
**Lambda Waiter** — CDK custom-resource pattern that polls an image build before creating the Runtime (ch06)
**LOG_ONLY / ENFORCE** — Policy Engine modes; ENFORCE hides denied tools from `list_tools` (ch05)
**MCP** — Model Context Protocol; primitives tools/resources/prompts, plus Sampling and Roots; transports stdio / Streamable HTTP (ch02, ch15)
**Memory Strategy** — Semantic, User Preference, Summary (built-in, override, or self-managed) (ch01, ch04)
**microVM** — Per-session isolated VM; sessions end at 8 h max or 15 min idle (ch01, ch08)
**Namespace (Memory)** — Per-user retrieval path isolating long-term records (ch04)
**Path A / Path B** — SharePoint ACL approaches: live OBO Copilot Retrieval API vs Azure AI Search with indexed ACLs (ch14)
**Plan-and-Execute / ReAct / Reflection** — Reasoning loops: committed plan; thought↔action; self-critique pass (ch02)
**Prompt caching** — Cache breakpoint after tools, before history; invalidated by prompt change (ch03, ch10)
**Provisioned Throughput** — Purchased Model Units (hourly, 1- or 6-month) (ch03, ch10)
**requires_access_token** — Identity decorator injecting OAuth tokens into an inner function (ch05)
**runtimeSessionId** — ≥16 chars; same ID shares microVM context, different ID isolates (ch04, ch07)
**Semantic Tool Selection** — Gateway search exposing only relevant tools out of thousands (ch01)
**Swarm** — Strands peer team handing off via `handoff_to_agent`; nondeterministic (ch09)
**Token Vault** — KMS-encrypted store for OAuth tokens/API keys (ch01, ch05)
**Transaction Search** — X-Ray session-level trace search; must be enabled (ch06, ch10)
**USAGE_LOGS** — Vended log of vCPU-hours / GB-hours (not tokens) for cost attribution (ch06, ch10)
**USER_FEDERATION (3LO) / M2M (2LO)** — Act as user with consent vs as the agent itself (ch01, ch05)
**Vended Logs** — DeliverySource + DeliveryDestination + Delivery per log type (ch06)
**Workflow** — Strands `workflow` tool: dependency-ordered tasks, auto-parallel, no branches/loops (ch09)
**Workload Identity** — Agent's own identity/ARN in the AgentCore identity directory (ch01)
