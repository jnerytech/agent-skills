# Glossary — Prompt Engineering for Generative AI

**Agent** — an LLM in a loop of action → observation → decision until it reaches a final answer; defined by inputs, a goal/reward and an action space (Ch 6)
**agent_scratchpad** — placeholder where an agent records its intermediate steps (Ch 6)
**Ask for Context** — let the model request the information it needs before answering (Ch 3)
**Blind prompting** — trial-and-error prompting with no evaluation loop (Ch 1, Ch 10)
**BPE (Byte-Pair Encoding)** — tokenizer that merges frequent character pairs into subwords; tiktoken implements it (Ch 2, Ch 3)
**CFG (Classifier Free Guidance)** — how strictly an image follows the prompt; ~7 is balanced (Ch 7, Ch 9)
**Chain of Thought (CoT)** — asking for step-by-step reasoning before the answer, i.e. "giving the model time to think" (Ch 1, Ch 6)
**Chunk overlap** — tokens shared between adjacent chunks so context survives the cut (Ch 4, Ch 5)
**Chunking** — splitting text by sentence, paragraph, topic, complexity, length or tokens (Ch 3, Ch 5)
**Context window** — the maximum number of tokens (input + output) per request (Ch 1–3)
**ControlNet** — conditions Stable Diffusion on a preprocessed reference such as edges, depth or pose (Ch 9)
**Denoising strength** — how much of the input image is replaced by noise: 0 keeps it, 1 is pure txt2img (Ch 9)
**Diffusion model** — generates images by iteratively denoising random noise, conditioned on text (Ch 7)
**Document chains** — Stuff, Refine, Map Reduce and Map Re-rank strategies for text larger than the context window (Ch 4)
**DreamBooth** — fine-tunes Stable Diffusion on 20–30 images of one concept bound to a rare token (Ch 9)
**DSPy** — a framework that searches over instructions and few-shot examples against a metric (Ch 10)
**ELI5** — "Explain it like I'm five" simplification prompt (Ch 3)
**Elo rating** — relative ranking from pairwise comparisons, as in Chatbot Arena (Ch 1)
**Embedding** — a vector of numbers placing text or images in latent space by meaning (Ch 5, Ch 7)
**Evals** — standardized test sets with reference answers or grading criteria (Ch 1, Ch 4)
**Few-shot / one-shot / zero-shot** — the number of worked examples in the prompt (Ch 1, Ch 3)
**Five Principles of Prompting** — Give Direction, Specify Format, Provide Examples, Evaluate Quality, Divide Labor (Ch 1)
**Function calling** — a model fine-tuned to emit JSON calls to developer-defined functions; `tool_choice` controls it (Ch 4, Ch 6)
**Ground truth** — reference answers that enable programmatic scoring (Ch 1, Ch 4)
**Hybrid search** — dense (semantic) plus sparse (keyword) vector retrieval (Ch 5)
**Img2Img** — generation guided by a base image; the image counterpart of a one-shot example (Ch 1, Ch 8, Ch 9)
**Information gain** — content the SERP lacks, sourced by interviewing the user (Ch 10)
**Inner monologue** — hidden reasoning in delimiters, stripped before the user sees the answer (Ch 3)
**Inpainting / Outpainting** — regenerate a masked region / extend the image beyond its frame (Ch 8, Ch 9)
**Latent space** — the continuous space of everything a model can represent; a prompt is a location in it (Ch 5, Ch 7)
**LCEL** — LangChain Expression Language; `prompt | model | parser` (Ch 4)
**Least to Most** — a chain that goes from general to specific, each step building on the last (Ch 3)
**LLM-as-evaluator** — a stronger model grades outputs on a criterion; must itself be validated (Ch 3, Ch 4)
**LoRA / Quantization** — efficient fine-tuning / reduced-precision weights for running open models (Ch 2)
**Majority vote** — repeat a classification and take the most frequent label (Ch 3)
**Meme mapping** — mining community prompts for word patterns that reliably produce an effect (Ch 8)
**Meme unbundling** — describing an artist's style as components instead of naming them (Ch 8, Ch 10)
**Meta prompting** — using an LLM to write prompts for another model (Ch 1, Ch 3)
**Metadata filtering** — restricting vector search with stored attributes (Ch 5)
**Negative prompt** — concepts to subtract (`--no` in Midjourney) (Ch 8, Ch 9)
**Output parser** — turns LLM text into typed objects; Pydantic is the most flexible (Ch 4)
**Permutation prompting** — `{a,b}` option sets expanded into a comparison grid (Ch 1)
**Plan-and-execute** — separate planner and executor agents, as in BabyAGI and AutoGPT (Ch 6)
**Prewarming (internal retrieval)** — ask for best-practice advice first, then use it to do the task (Ch 1)
**Prompt editing** — `[from:to:when]` switches the prompt mid-generation (Ch 9)
**Prompt rewriting** — an LLM rewrites a user's raw prompt before image generation (Ch 8)
**Query planning** — decomposing a query into a dependency graph of sub-queries (Ch 4)
**RAG** — Retrieval Augmented Generation: retrieve relevant chunks and insert them as context (Ch 5)
**ReAct** — Reason + Act loop: thought → action → observation until a final answer (Ch 1, Ch 6)
**Reference text** — supplied documents the model must answer from, with a fallback "not found" (Ch 3)
**RLHF** — demonstrations → supervised policy → reward model + PPO (Ch 2)
**Role prompting** — "act as a…" persona, ideally set in the system message (Ch 1, Ch 3)
**SAM (Segment Anything)** — click-to-mask segmentation model used for inpainting and ControlNet (Ch 9)
**SDXL refiner** — a second model that adds fine detail after the base model; "Switch at" sets the split (Ch 9)
**Seed** — the initial noise; fix it for reproducibility (Ch 1, Ch 7)
**Self-evaluation** — a follow-up call that rates or critiques the previous output (Ch 1, Ch 3)
**Self-Querying retriever** — an LLM extracts metadata filters from a natural-language query (Ch 5)
**Sliding window chunking** — overlapping fixed-size windows advanced by a step size (Ch 3)
**Stop sequence** — a string that halts generation, e.g. before an invented tool result (Ch 6)
**Style unbundling** — extracting a text's tone, vocabulary and structure into a reusable guide (Ch 3)
**Temperature** — randomness of next-token sampling (Ch 1)
**Token** — the unit LLMs predict, about ¾ of a word (100 tokens ≈ 75 words) (Ch 1, Ch 2)
**Transformer / self-attention** — architecture where every token weighs every other token's relevance (Ch 2)
**Tree of Thoughts (ToT)** — searches over multiple reasoning paths with self-evaluation and backtracking (Ch 6)
