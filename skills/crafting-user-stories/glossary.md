# Glossary — The Art of Crafting User Stories

**A/B testing** — comparing two versions of a product to see which performs better (Ch 2).
**Acceptance criteria** — conditions that must be met for a story to be considered done (Ch 1, Ch 3).
**Accessibility** — designing so people with disabilities can use the product; follow WCAG (Ch 2).
**Action** — the second core story component: the specific thing the user wants to do (Ch 1).
**Agile** — iterative approach delivering working software frequently, responding to change (Ch 1).
**ATDD (Acceptance Test-Driven Development)** — uses stories to define acceptance tests up front (Ch 1).
**Backlog refinement (grooming)** — ongoing review to clarify, split, estimate, and re-order backlog stories (Ch 6).
**BDD (Behavior-Driven Development)** — defines behavior/acceptance from stories (Ch 1, Ch 3).
**Cost of delay** — economic loss from not delivering a feature now; numerator input to WSJF (Ch 4).
**Definition of Done (DoD)** — shared checklist a story must satisfy to be complete (Ch 6).
**Definition of Ready (DoR)** — criteria a story must meet before entering a sprint (Ch 6).
**Design sprint** — GV's 5-day Understand→Define→Sketch→Decide→Prototype process (Ch 2).
**Design thinking** — empathize→ideate→prototype→test problem-solving with the user at center (Ch 2).
**Empathy map** — visual of a user across Says / Thinks / Feels / Does quadrants (Ch 2).
**Epic** — a large story too big for one sprint; split into smaller stories (Ch 1, Ch 3).
**Estimable** — the "E" in INVEST: effort can be sized (Ch 1).
**Fibonacci scale** — 1,2,3,5,8,13… sequence used for story-point estimation (Ch 4).
**Goal** — the third core story component: the desired outcome/benefit (Ch 1).
**INVEST** — Independent, Negotiable, Valuable, Estimable, Small, Testable — story quality criteria (Ch 1).
**Kano model** — Noriaki Kano's classification of needs into Basic / Performance / Delight (Ch 4).
**LeSS (Large-Scale Scrum)** — scaling framework; backlog items managed by the Product Owner (Ch 1).
**MoSCoW** — prioritization: Must / Should / Could / Won't Have (Ch 4).
**MVP (Minimum Viable Product)** — smallest releasable product that delivers value (Ch 4, Ch 7).
**#NoEstimates** — movement questioning the value of detailed up-front estimation (Ch 4).
**Persona** — fictional, research-based character representing a user segment (Ch 1, Ch 2).
**Planning poker** — collaborative, consensus story-point estimation using cards (Ch 4, Ch 6).
**Product backlog** — prioritized list of stories the Product Owner orders by value (Ch 1).
**Product Owner** — represents the user's voice; prioritizes the backlog (Ch 1, Ch 5).
**RICE** — prioritization scoring: Reach, Impact, Confidence, Effort (Ch 4).
**Story mapping** — arranging stories along the user's workflow to visualize the whole journey (Ch 4, Ch 6).
**Story point** — relative unit of effort/complexity, not time (Ch 4).
**Story splitting** — breaking a large story into smaller ones by workflow, business rules, data, or operations (Ch 6, Ch 7).
**Stakeholder** — anyone with interest in the product: PO, customer, developer, designer (Ch 5).
**Testable** — the "T" in INVEST: can be verified against user needs (Ch 1).
**Theme** — a group of related epics/stories around a larger objective (Ch 4).
**Touchpoint** — any point of interaction between user and organization (Ch 2).
**T-shirt sizing** — rough relative estimation (S/M/L/XL) (Ch 4).
**Unconscious bias** — automatic stereotyped beliefs that skew design decisions (Ch 2).
**Usability testing** — observing real users interacting to find friction (Ch 2).
**UCD (User-Centered Design)** — framework involving users at every design stage (Ch 2).
**User journey map (CUJ)** — visual of the steps + emotions a user has reaching a goal across touchpoints (Ch 2).
**User research** — collecting data on user needs, behaviors, preferences (Ch 2).
**User story** — short, informal feature description from the user's perspective (Ch 1).
**Velocity** — amount of story points a team completes per sprint; used for forecasting (Ch 4).
**WSJF (Weighted Shortest Job First)** — `(Business Value + Opportunity Enablement + Time Criticality + Risk Reduction) / Job Size` (Ch 4).
